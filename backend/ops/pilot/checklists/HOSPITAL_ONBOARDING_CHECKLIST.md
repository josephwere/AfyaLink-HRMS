# Pilot Hospital Onboarding Checklist

## Pre-Onboarding
- [ ] Contract and data processing terms signed
- [ ] Integration endpoints inventoried
- [ ] Security contacts nominated
- [ ] Clinical champions nominated

## Technical Setup
- [ ] Hospital and branch records configured
- [ ] Roles and permissions validated
- [ ] SSO/2FA policy confirmed
- [ ] Connectors configured (FHIR/HL7/webhooks)

## Data Migration
- [ ] Data mapping approved
- [ ] Dry-run completed
- [ ] Reconciliation passed
- [ ] Cutover rollback point validated

## Go-Live
- [ ] Training completed by role
- [ ] Hypercare channel active
- [ ] Incident escalation contacts confirmed
- [ ] Daily pilot KPI report enabled
